## Gotchas

- **Linter green is not parity.** `skill-portability-check.py` reads frontmatter
  only. A skill set `"off"` in `skillOverrides` passes it and still never fires in
  Claude Code, while Codex (which ignores that file) loads it. Found 2026-09-12:
  12 canonical skills off in Claude, live in Codex.
- **Views are links into canonical.** Anything that writes into
  `~/.agents/skills/<owned>/` by path writes canonical. `graphify install
  --platform agents` does exactly that and overwrites the Claude variant — upgrade
  graphify with `--platform claude` only.
- **Concurrent sessions commit your work.** `closeout` in another session sweeps
  every uncommitted change in the repos it visits. Commit the report as soon as it
  is written, not at the end of a long session.
- **Description length has a budget.** Claude Code caps the combined skill
  description size; very long descriptions risk a skill silently dropping out of
  the listing. When recommending a sharper `Do not use` clause, keep the whole
  description near 650 characters.
- **`dcg` blocks some shell shapes** (`rm -rf` inside heredocs, `$VAR` redirects,
  `git` inside command substitution). Use Python `subprocess` or literal paths;
  do not try to bypass the guard.
