The "ZeroEdit" pipeline Eric wants to replicate: Phase 0 deconstruct winning channels' formulas with Claude Code → Phase 1 find outlier topics (1of10, ≥2× outlier score, recent) → Phase 2 deep-research + script beats (human rewrites the words) → Phase 3 record own voice, enhance via Auphonic API → Phase 4 timestamp audio + generate synced images via Higgsfield CLI → Phase 5 Claude assembles the finished video (~$2/45-min video). Key rules: no AI voiceover, no verbatim AI scripts, medium model strength for execution / max for foundational research.
