## 1. What this project is

A unified grading system for Baylor Football player personnel that couples
**Telemetry (Teamworks) trait percentiles** with the internal **S.T.A.Q.S.**
grading scale, so incoming transfer-portal data gets filtered down to the
players who deserve a scout's time.

Two inputs, one system:

- The scout's **STAQS grade is the grade of record.**
- Telemetry percentiles are **threshold flags** that say who to review and which
  STAQS factors the data already supports.

Nothing is averaged, weighted, or blended into a composite. That was an explicit
design decision, not an oversight (§5).

Audience for the deliverables is recruiting and personnel staff, not analysts.

## 4. The S.T.A.Q.S. system

Eight factors, each scored **1 / 3 / 9**, summing to **8-72**.

Five critical factors (all positions): **S**ize, **T**oughness, **A**thletic
Flexibility, **Q**uickness, **S**peed. Plus **3 position-specific** factors. QB
has its own set of 8.

Tiers (also loaded as the Player Grade dropdown in Telemetry Scout Reports >
Settings):

| Grade | Score | Elite traits | Color |
|---|---|---|---|
| AA | 60-72 | 7-8 | green `00B050` |
| AL | 48-59 | 5-6 | yellow `FFC000` |
| QS | 40-47 | 3-4 | black `404040` |
| FRP | 30-39 | 1-2 | grey `D8D8D8` |
| LIM | 24-29 | 0-1 | pink `ED6363` |
| NGE | 8-23 (dropdown 0-23) | 0 | red `C00000` |

## 5. The bridge (Telemetry to STAQS) — the core algorithm

Implement exactly this. Every constant lives on the workbook **SETTINGS** tab
and must stay editable there rather than hardcoded in formulas.

```
elite trait      := Telemetry percentile >= 75
deficiency       := Telemetry percentile < 25
graded traits    := traits with a numeric percentile for that player
elite share      := elite traits / graded traits
```

Elite share (not raw count) is used because positions carry different numbers of
Telemetry traits — OL has 2, LB has 8 — so a raw count would systematically
punish linemen.

Share maps to a projected band using the GRD SCALE's own elite-trait cut lines:

```
>= .875 (7/8) -> AA
>= .625 (5/8) -> AL
>= .375 (3/8) -> QS
>= .125 (1/8) -> FRP
   0          -> LIM, or NGE when deficiencies exceed elite traits by 2+
                 with no elite share
```

Guards and flags:

- **Minimum 2 graded traits** to project a band; otherwise the row is `THIN`.
- **REVIEW** fires at elite share >= .375 (the QS floor), or when the Speed
  alert or Impact alert fires, for any row with at least one graded trait.
- **Speed alert**: Play Speed or Deep Speed >= 90 ("documented difference making
  SPEED" on the GRD SCALE).
- **Impact alert** (009, decided 2026-09-16): Player Impact >= 90. Fires on its
  own and turns REVIEW on. Chosen after the validation run caught 6 of 13
  missed QS-or-better players at 90.
- **Low Impact alert** (009): a REVIEW row with Player Impact <= 10. A caution
  note only; it never removes REVIEW.
- **Size-Speed alert**: poor size with elite speed — the GRD SCALE's "must be
  special and offer a role" exception.
- **LOW SAMPLE** below 150 snaps. Telemetry itself blanks most traits under
  roughly 100 snaps.
- **Profile REVIEW** (013, decided 2026-09-26): the position's two must-haves
  (SETTINGS POSITION PROFILES) both at or above their floors, 200+ snaps, and
  the position's 2nd-path switch on (OT, OG, C, EDGE). Turns REVIEW on. A blank
  must-have counts as not cleared. Must-have status, Profile and the Diamond
  signal show for every position as information only.

**What data can and cannot grade.** Data directly supports 4 of the 5 critical
factors (Speed, Quickness, Athletic Flexibility, Size from HT/WT) and offers
proxies for Toughness. Position-specific factors get partial support (see the
CROSSWALK tab). FBI, wiring, keep-ability, character, and medical are **never**
data-graded.

## 6. Workbook structure (003 layout; 010 is current, same layout as 009)

Tabs, in order:

- **README** — what it is, the bridge, how to use, scope, cell legend, sources.
- **SETTINGS** — thresholds (rows 5-12 in 009, including the two alert cut
  points at rows 11-12), band cut lines, simplified size standards by position.
  *All tuning happens here.*
- **GRADE SCALE** — the six tiers.
- **METRIC GLOSSARY** — what each Telemetry metric measures.
- **CROSSWALK** — which Telemetry metric informs which STAQS factor, by position.
- **POSITION MAP** — Telemetry position codes -> Baylor eval tabs -> trait counts.
- **PORTAL INPUT** — the data sheet, columns A:BO (67) plus PlayerId, raw
  position, Elusiveness and source file in BP:BS from 008 on. Grouped as Player
  Traits (all positions, P:AC) / QB Traits (AD:AI) / Advanced Stats (AJ:BN).
  Percentiles 0-100; blank where a position carries no metric. HT in inches
  (6'1" = 73). **REVIEW BOARD reads these columns by fixed position, not by
  header, so never insert, delete or reorder PORTAL INPUT columns.** Load data
  with `load_leaderboard.py`, which maps CSV headers onto the template's
  columns.
- **REVIEW BOARD** — all formulas, do not hand-edit. One row per PORTAL INPUT
  row. Columns: traits graded, elite traits, deficiencies, elite share,
  projected band, REVIEW?, speed alert, size-speed alert, Impact alert and Low
  Impact alert (N:O, 009), critical deficiency, data-suggested SIZE / TOUGH /
  ATHLETIC / QUICK / SPEED values, best and worst trait, plus roster metadata.

**Cell legend:** yellow fill `FFF2CC` with blue text = user input. Black text =
formula.

**House styling** (workbooks and companion docs both): Arial throughout unless
the Baylor-style variant is called for; titles Arial 12pt bold Baylor green
`154734`; subtitles and notes 9pt grey `595959`; table header rows white bold on
`154734`; tier fills per §4. The "Baylor style" variants (003 xlsx, 005 docx)
additionally use NCAA Baylor Bears / Baylor Bears Font display type and
Bahnschrift body, with a black masthead bar. Those fonts render only on a
machine that has them installed; Word substitutes elsewhere.

## 7. Telemetry platform notes

Telemetry Sports (app.telemetry.fm, branded Teamworks) is the recruiting and
scouting platform. Login is the user's; an agent without a browser session
cannot reach it.

- **Transfer Portal** > Player Traits / Advanced Stats / Boxscore. Traits and
  stats appear only after filtering to a position or position group.
- **Scout Reports > Settings** holds the Player Grade dropdown, already loaded
  with the six STAQS tiers. Scout reports carry a numeric Score (0-72) plus the
  grade.
- **Documentation** pages (Glossary, Player Traits, Advanced Stats) embed
  signed-URL PDFs from s3 docs.telemetry.fm. The PDFs, not the UI tooltips, are
  the reliable definition source.
- Traits and advanced stats are **0-100 percentiles vs the same position** (FBS,
  2019-present, in-game tracking). Exceptions: Top End Speed is raw mph; QB Risk
  Level is a text label; Tackle Breaking is documented but absent from the
  portal grid; QB decision-making surfaces as "Target Selection"; the DB
  coverage stat surfaces as "EPA/Target".
- High school prospects have **no** Telemetry data. Grade them on the STAQS eval
  keys as usual.

### Scraping the portal (proven 2026-09-02, read-only)

- The table is **virtualized** (~20 rows in the DOM) at 100 rows per page.
  Scroll the table's scroll container, then click "Next page" by aria-label.
  Row key = name + Previous + Entered. About 3 s per page.
- Filter panel: Position combobox (remove chip, type code, click option), "Enter
  snap count" input, date range via calendar. Each calendar month arrow moves
  **two** months; the end date cannot exceed Telemetry's own "today".
- **"Apply Filters" sometimes needs a second click.** Verify the "Filter (n)"
  count afterward.
- If the pager shows Next disabled on page 1, reload. The filter survives a
  reload but window state does not, so **export scraped data before reloading.**
- Move big payloads out of the browser as gzip+base64.

## Settings currently implemented

- Elite percentile 75, poor percentile 25
- Minimum snaps 150 (LOW SAMPLE warns below this, does not suppress)
- Speed alert: Play Speed or Deep Speed at 90th percentile or higher, fires
  independently of the elite-share gate
- Review trigger: elite-trait share at or above 0.375
- Minimum graded traits to project a band: 2, else THIN
- Impact alert (009): Player Impact 90 or higher, fires independently and turns
  REVIEW on for rows with trait data (NO DATA rows never show REVIEW)
- Low Impact alert (009): REVIEW row with Player Impact 10 or lower; note only
- Tackling stays a counted IDL trait (decided 2026-09-16)
