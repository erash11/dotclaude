## Settings currently implemented

- Elite percentile 75, poor percentile 25
- Minimum snaps 150 (LOW SAMPLE warns below this, does not suppress)
- Speed alert: Play Speed or Deep Speed at 90th percentile or higher, fires
  independently of the elite-share gate
- Review trigger: elite-trait share at or above 0.375
- Minimum graded traits to project a band: 2, else THIN
- Impact alert (009): Player Impact 90 or higher, fires independently and turns
  REVIEW on for rows with trait data (NO DATA rows never show REVIEW)
- Low Impact alert (009): REVIEW row with Player Impact 10 or lower; note only
- Tackling stays a counted IDL trait (decided 2026-09-16)

## Gotchas

- Read Drive workbooks with the API, not the mount (default from 2026-10-17):
  `gws drive files get --params '{"fileId":"<id>","alt":"media"}' -o <local>`.
  019 in the Drive root is id `1bMYW1prGDsSymnquKMJAIruQvINWDB35` (a second copy sits in Send/).
  The mount hung at 0 bytes on 019 twice, even after a Drive restart.

- `pull_week.bat` / `PULL WEEK.bat` puts the export folder path on the clipboard at READY (replaces whatever was there). Refresh All on 44 files took 331-354 s on this laptop 2026-10-06, not the 2-4 min UPDATE DATA mentions. Hand-downloaded CSVs: run `check_exports.py` or read LOAD STATUS Column check; Download CSV writes only on-screen columns.
- `telemetry_pull.py` uses one Chrome profile (`%LOCALAPPDATA%\telemetry-pull`);
  only one run at a time. Two sessions pulling at once lock each other out
  ("Opening in existing browser session"), and a hung diagnostic holds the lock.
  Chrome's download manager crashes this machine's automated Chrome a few
  seconds after a download; the tool no longer uses it (page CSV captured
  instead). Do not revert to `expect_download`/`save_as`.
- Telemetry's scope multiselect will not remove its last chip, and options carry
  no selected attribute. `set_scope` adds the wanted scope first, then clicks the
  other chips' x buttons. If the UI changes again, `--probe` and the diagnostic
  in the 2026-09-29 handoff show the DOM.
- The Telemetry API host is `snowshoe-api-coaching.telemetry.fm`. Standing rule 3
  still applies: no token, no internal API. Stay with the rendered-UI pull.
- `codex exec -o <file>` saves only the one-line summary; the full report is the last
  `+++ b/codex_verification_*.md` block in the run log. From `%TEMP%/pp015` add
  `--skip-git-repo-check`. Codex hit its usage limit 2026-09-30 afternoon.
- Codex companion jobs cannot be cancelled from Git Bash (`taskkill /PID` gets
  path-mangled); a stale `task-mun50b68-8oa2ce` may still show as running. Clear
  with `/codex:cancel`. Direct `codex exec -m gpt-6-astra ... -o <file>` works.
- Low memory (other Claude sessions, WSL) killed a Codex run; `check_workbook.py`
  holds two 20k-row workbooks in memory.

- **014 is query-driven. Never run `load_leaderboard.py`, `add_benchmark.py`
  or `add_profiles.py` on it**; new data goes in through Refresh All. To change
  the loader, edit `scripts/powerquery/*.m` and `load_leaderboard.py` together
  and rebuild 014-style workbooks with `make_self_service.py`.
- Excel query tables insert whole columns when created and on their first
  refresh (they shifted REVIEW BOARD references 72 columns and moved a named
  cell). `make_self_service.py` refreshes each table before writing layout and
  rewrites the REVIEW BOARD formulas afterwards. Later refreshes use overwrite
  style and shift nothing (tested).
- pywin32 ignores the `After=` keyword on `Worksheets.Add`; pass it
  positionally, `Add(None, sheet)`.
- `Excel.CurrentWorkbook()` plus `Folder.Files` needs privacy levels ignored:
  set by `wb.Queries.FastCombine = True`, saved in the file (verified after
  reopen).

- **012 and 013 are not load templates.** `load_leaderboard.py` clears rows but
  not the Benchmark tag or profile columns. Load onto 010, then rerun
