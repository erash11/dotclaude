Every document going to Baylor Athletics administration (leadership, admin, Kenny Boyd,
Chris Ruf) is built with the house style in `~/DEV/Program/Baylor_Doc_Style`
(`baylor_docstyle.py`, `BaylorDoc`; exemplar is the Software & Technology Management
Framework draft, chosen 2026-08-30). Use only its components (`section`, `table`, `note`,
`para`, `bullets`) and its defaults: Calibri 10.5, 9.5pt tables, 0.80/0.90in margins.
No local font sizes, margins, Normal-style overrides or hand-built tables.

**Why:** on 2026-09-29 I shrank the Tech Inventory by-unit list (7.5pt, 0.6in margins,
custom table) to force one page. Eric: "the docs should have the same baylor styling
we've been using in other documentation. make a note that future docs going to
administration should use it also." When asked, he chose two pages in house style over
one page that broke it.

**How to apply:** if content won't fit a page limit in house style, ask Eric (more pages,
or cut content) instead of shrinking below house sizes. Word COM is the page-count
authority (`doc_platform.word_pdf` in Tech_Inventory_Analysis). Related:
[[tech-inventory-refresh]], [[kenny-boyd-doc-review-preferences]],
[[baylor-department-names]].
